UGV Localization with UAV-Assisted Positioning

UGV Localization

Use UAV-assisted positioning to estimate the UGV pose when its GNSS is degraded or unavailable.

This is the current design contract. It is not implemented yet.

Planner pose input

The planner needs the UGV pose, traversability map, and goal in the same coordinate frame.

A route can be correct while the UGV follows it incorrectly if its estimated pose has drifted.
Localization Estimates the current UGV pose.
Traversability Marks the terrain the UGV can cross.
Planning Uses the pose, terrain, and goal to generate a route.

UGV GNSS loss

GNSS provides a global position while it is available. If it drops out, wheel odometry and the IMU still track motion, but their errors accumulate.

The subsystem keeps publishing a pose. As the estimate drifts, its covariance should increase to show that the pose is less certain.

UAV correction

Assumption

The UAV keeps reliable localization while UGV GNSS is unavailable.

Measurement

The UAV provides a noisy observation of the UGV position relative to itself.

Hardware

UWB, AprilTags, or camera tracking could produce this measurement later. The current interface does not require one.

Project interfaces

Localization and traversability are separate. Both publish data in map so route planning can use them together.

Subsystem scope

The subsystem estimates the UGV pose. It does not map terrain, generate routes, or control either vehicle.

In scope

  • UGV pose estimation
  • GNSS degradation behavior
  • Odometry and IMU fusion
  • UAV relative-position corrections
  • Pose covariance
  • Planner-facing pose output

Not in scope

  • Terrain classification
  • Path generation
  • UAV path planning
  • Full SLAM
  • Loss of localization for both vehicles
  • Commitment to UWB or camera hardware

This supports search-and-rescue routes where UGV GNSS may be degraded and the UAV still has reliable localization. It does not solve localization if both vehicles lose their global reference.
