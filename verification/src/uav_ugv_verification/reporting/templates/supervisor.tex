\section{Architecture and assumptions}
The UGV controller has five persistent supervisor modes: INIT, NAVIGATE, HOLD\_GUARD,
HOLD\_FAULT, and GOAL. Only NAVIGATE permits the existing path follower; all other modes
request zero linear and angular velocity. The existing full pose and route guards remain authoritative.
Memory includes a fault latch, a clear-decision counter, recovery age, and completed-goal memory.
The completion latch prevents estimated drift or intervening holds from restarting the same goal.
It records an estimated-threshold observation, not R2's independent physical/quiet dwell.
The supplied decision-precedence diagram is available separately as \texttt{figures/supervisor.pdf}.
The detector boundary is optional and disabled in the camera deployment because no online producer
is available. When enabled, missing, stale, invalid, or discontinuous decisions hold. Recovery requires
ten distinct valid clear decisions and at least five simulation seconds from the first clear acquisition
stamp, with fresh latest evidence. New goals never clear fault recovery.
\section{Formal method and implementation}
A versioned decision table generates C++ mode-selection data and supplies a Python reference model.
Independent temporal safety and next-step predicates constrain permission, completion, resets,
readiness, and exact recovery-memory updates. An independently maintained completion monitor is
composed with the reachable-state graph. Examples include
\[
G(\mathrm{permit}\rightarrow\mathrm{goalValid}\land\mathrm{poseValid}\land
\mathrm{routeValid}\land\neg\mathrm{faultLatch}\land\neg\mathrm{done})
\]
and \(G(\mathrm{done}\land\neg\mathrm{newGoal}\rightarrow X\mathrm{done})\).
Breadth-first exploration includes all latch/counter memory and recovery-age classes;
it is exhaustive finite-state safety checking rather than only mode/input enumeration.
Exact numerical tests establish timestamp/freshness boundaries, including five seconds plus/minus one nanosecond.
The pure C++ transition and validators have no ROS/Gazebo imports. Every received detector decision
updates recovery, including alarm/clear bursts. The ROS controller reevaluates permission before
periodic command publication. Policy and implementation digests bind the compiled probe to the checked sources.

\section{Scope and course connection}
The proof concerns finite decision logic under validated-input and time-abstraction assumptions.
It does not prove delivery, scheduling, perception, learned detection, continuous clearance, or physical
braking. Clock epochs are locally inferred; message types do not identify numerically coincident old
messages after rewind. Timing and physical stopping remain separate measured trace claims.
Historical M3/M4 cohorts are not retroactively covered by this proof.
